About

I’m an AI engineer and machine-learning researcher. I’m completing an M.Sc. in Electrical and Software Engineering at the University of Calgary, where I study how reliable LLM-based coding agents really are: when they hallucinate packages, APIs or library versions, how they edit and rewrite code, and what retrieval and verification change about that behaviour.

My recent work includes a large-scale empirical study of AI coding agents published at MSR 2026, models that estimate the security risk of AI-generated code, and a multi-agent system for security triage of cryptographic code. My projects usually run end to end, from a well-designed dataset and evaluation to a model running as a service with FastAPI, Docker and AWS.

Before moving to Canada, I studied Electrical and Telecommunications Engineering at Amirkabir University of Technology in Tehran and worked as a machine-learning intern on speaker verification.

I’m looking for AI/ML engineering and applied research roles. The best way to reach me is by email.

Research

I work on evaluation and reliability of LLM agents, AI-generated code security, and software engineering for machine-learning systems.

Publications

  1. Behavioral Analysis of AI Code Generation Agents: Edit, Rewrite, and Repetition

    MSR 2026, Mining Challenge Track. ACM. Co-first author.

    An analysis of 23,534 real-world pull requests from five AI coding agents, using similarity- and entropy-based metrics to measure how often agents edit, rewrite or repeat code, and to surface systematic failure patterns.

    Paper Code Conference page

Current work

Hallucination and reliability in LLM coding agents

Since Feb 2026

I ran a 105-task pilot comparing package, API and version hallucinations across four commercial and open-weight LLMs, built on controlled test cases so results can be reproduced. I’m now comparing one-shot and multi-step agent workflows: unsupported claims, the effect of retrieval and verification, error correction, failures that tests miss, and false reports of success.

Projects

Security risk analysis for AI-generated code

2025

A pipeline over 105,544 files from 4,969 security-related pull requests. CodeBERT embeddings feed a LightGBM model that estimates file-level risk alongside Semgrep findings; results and suggested fixes are served through a FastAPI app with PostgreSQL, deployed on AWS EC2 with Docker and GitHub Actions.

Python, CodeBERT, LightGBM, Semgrep, Gemini API, FastAPI, PostgreSQL, Docker, AWS

Multi-agent security triage for cryptographic code

2025

A JADE multi-agent system that combines a fine-tuned CodeBERT classifier with Semgrep analysis to prioritize risky C/C++ cryptographic code. Inference, severity analysis and reporting run as separate services, so each decision can be traced.

Java, JADE, Flask, CodeBERT, Semgrep

Detecting AI-generated code in cryptographic software

2025

Datasets of human-written and GPT-4o-generated AES-related C/C++ functions, used to train CodeBERT classifiers. Repository-aware cross-validation and tests on unseen repositories measure how well detection generalizes.

Python, CodeBERT, GPT-4o

Autism spectrum disorder detection with transfer learning

2025

A fine-tuned VGG16 model for detecting ASD from behavioural imaging data, tuned with Keras Tuner to reduce overfitting, with Grad-CAM saliency maps that show which image regions drive each prediction.

Python, Keras, TensorFlow, Grad-CAM
